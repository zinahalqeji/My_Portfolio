# Zinah Al Qeji — Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or serve the folder using a simple local HTTP server.

## Publish on GitHub Pages
Upload the **contents of this Portfolio folder** to the root of your GitHub repository, then enable GitHub Pages in Settings → Pages (Deploy from a branch, main / root).

## Project links
Three projects have supplied live-demo URLs: Wedding Invitation App, Nordtech ETL Pipeline, and Demo Page. Other projects use repository URLs where available, or the GitHub profile when a direct URL is not verified.

## Contact
The contact action opens the visitor's email application. No backend form service is configured.

## Notes
The original theme and animations were preserved. Skill percentages are carried over from the original site and should be reviewed before publishing. External links and live applications require online access.
